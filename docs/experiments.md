# Experimental Results and Model Benchmarks

This document details the training experiments performed and compares the resulting models.

## Experiment Overview

Two primary training runs were conducted using YOLO11 Small (`yolo11s.pt`) on the custom 8,888-sample airborne object detection dataset.

| Run Name | Architecture | Epochs Completed | Batch Size | Image Size | Precision | Recall | mAP@50 | mAP@50-95 | Location |
| :--- | :--- | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :--- |
| **Run 1** (`train`) | YOLO11s | 35 | 16 | 640 | 0.8728 | 0.8325 | 0.8882 | 0.5496 | `runs/detect/train/` |
| **Run 2** (`train2`) | YOLO11s | 57 | 16 | 640 | **0.8884** | **0.8442** | **0.9002** | **0.5648** | `runs/detect/train2/` |

**Default Model Checkpoint**: `weights/best.pt` (sourced from Run 2, achieving **90.0% mAP@50** and **56.5% mAP@50-95**).

## Visual Diagnostic Plots

Diagnostic plots generated by Ultralytics during training are preserved in `runs/detect/train2/`:
- `results.png`: Training and validation loss trajectories alongside precision, recall, and mAP progressions.
- `confusion_matrix.png`: Normalized class prediction matrix demonstrating low confusion between Bird and Drone.
- `F1_curve.png`: Optimal F1 confidence threshold peaking near `0.45 - 0.55`.
- `PR_curve.png`: High area under Precision-Recall curve across all three target categories.
